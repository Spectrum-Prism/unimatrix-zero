# hello-world

The first project in unimatrix-zero: a Python script that prints a greeting.

## Requirements

Python 3.8 or newer. No third-party packages.

## Run it

```bash
cd projects/hello-world
python3 hello.py          # Hello, World!
python3 hello.py Rob      # Hello, Rob!
```

Or make it executable and run it directly:

```bash
chmod +x hello.py
./hello.py
```
